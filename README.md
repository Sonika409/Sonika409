### Things I've built

| Project | The story |
|---|---|
| **Aadhaar Enrolment Analytics** — UIDAI Data Hackathon 2026 | Analysed enrolment across 36 states/UTs and 3 age groups. The 0–5 age group dominates overall, but Bihar, Manipur, Sikkim, Meghalaya, and Mizoram broke the pattern — useful for deployment and campaign planning. |
| **Subscription Platform Profitability Analysis** | A "declining profit" problem turned out to be a retention crisis, not a cost one — 33% of users were one-time buyers, and nobody transacted more than 3 times. |
| **Hospital ER Analysis** | Built a dashboard tracking admissions, wait times, and satisfaction. Found 61% of patients faced delays, averaging a 35.5-minute wait. |
